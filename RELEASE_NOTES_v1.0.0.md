# v1.0.0

First public release, archived on Zenodo with the paper "What Do We See When We Look at Food? Category and Semantic Structure in Food Representations" (Carlson, Katsoulis, Hebart & Avery).

- `bash run_all.sh quick|full` reproduces the analyses, tables (CSV) and figures from the anonymised trial data (doi:10.5281/zenodo.23498576) and the PAFID item information (doi:10.5281/zenodo.23226251).
- Includes the paper's SPoSE seed-20 solution and the cached component annotations, so no API key or retraining is needed.
- Includes the review-round sensitivity analyses in `sensitivity/`.
- Not included: the 82 participants excluded before analysis, so the exclusion-sensitivity analyses cannot be rerun from the public data.
